# Developer Content and Publication

This module owns gradual preparation of complete development content, required-field validation, reviewed mappings and public updates. The developer publishes reviewed materials; publication does not require routine administrator approval.

Requirements: FR-15–FR-22, NFR-03 and NFR-06. See [[requirements]].

## Workspace

Global sections are My developments, Enquiries, Company and Account settings. Each development contains Basic information, Description and gallery, Buildings and floors, Floor plans, Apartments and finishing, Map and infrastructure, Parking, Site 3D and panoramas, and Preview and publication. [[navigation]] explains each section's responsibility.

## Private preparation

The developer can save partial sections and uploads, leave the workspace and resume the draft later. Missing required data or translations does not prevent private saving. An explicit save workflow satisfies this requirement; automatic saving is not assumed. Private content is protected across API, file and direct-link access.

## Initial publication minimum

| Area | Required information |
| --- | --- |
| Identity and location | Development name, city, address, map point and cover. |
| Public content | General development description in Russian, Kazakh and English; all populated public descriptions/captions have the three versions. |
| Construction | Status; planned quarter/year when Under construction. Housing class is optional. |
| Buildings and floors | All declared buildings and residential floors, supplied facades and floor plans, and valid reviewed floor/apartment links. |
| Apartments | Number, building/floor, rooms, area, bathrooms, 2D layout, base condition, base price and availability. |
| Parking | Scheme, place identifiers, availability and applicable commercial information when parking is offered. |

Extra finishing variants, example photos, 3D scenes, panoramas and a minimum infrastructure-point count are not publication prerequisites. Optional supplied content still satisfies its applicable validation rules. Proper names, addresses and identifiers are exempt from separate text translation.

Preview identifies each blocker and the editing section responsible for it. Initial publication exposes the complete eligible development, rather than publishing incomplete sections separately.

## Changes after publication

Every valid saved change becomes public immediately, including descriptions, plans, reviewed geometry, media, prices and availability. There is no extra republish action or separate editorial draft for these changes. Invalid public saves cannot leave the public record in a state that violates required rules.

AI geometry remains a candidate until reviewed and saved. Background completion does not publish a draft or clear a restriction. An administrator's hide/suspension remains independent of content completeness; an ordinary save cannot restore restricted content.

Acceptance covers draft persistence across sessions, accurate blockers, a base-only apartment, optional-content absence, complete first publication and immediate valid updates. [[regions]], [[languages]] and [[states]] define the related rules.
