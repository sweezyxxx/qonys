# Language and Content Rules

QONYS supports Russian, Kazakh and English in the interface, buyer assistant and populated public descriptions. These are three separate content responsibilities.

## Language responsibilities

| Layer | Rule | Validation |
| --- | --- | --- |
| UI | Labels, state text, validation and navigation follow the selected interface language | Critical flows are checked in all three locales. |
| Buyer assistant | The reply follows the buyer's message language independently of the UI | Equivalent request meanings check extraction, explanation and reply language. |
| Public developer content | Every populated description/caption has Russian, Kazakh and English text versions | Private incomplete versions can be saved; public validation requires the three versions. |

The public-text rule includes development, apartment, finishing and company descriptions and gallery captions. Proper names, addresses and identifiers do not need separate translation. Plans and images retain their original content. Automatic translation is not part of the selected workflow.

## Structured text

The developer form uses a general description, optional courtyard/landscaping and infrastructure descriptions, and a gallery with optional captions. Text uses paragraphs and line breaks in labelled sections. An unrestricted visual page builder is outside the design.

An optional description or caption can be absent. Once populated for public display, it requires all three versions. A private draft can hold work in progress without becoming public. The general development description remains part of the first-publication minimum.

## Commercial wording

Finishing labels are supported reference values, while the developer describes what the offered condition includes. The selected offer shows its full apartment price. A From label is used when a catalogue card presents the minimum offered price; it does not replace the selected detail-page price.

Availability wording distinguishes Available, Reserved and Sold. Enquiry-processing wording distinguishes New, In progress, Processed and Cancelled. Neither set is a payment or reservation operation.

## Supplied assets

Optional photographs, GLB scenes and panoramic JPEGs belong to their intended development, apartment or offer. Empty optional sections are hidden. The asset's presence never determines the base physical finishing condition.
